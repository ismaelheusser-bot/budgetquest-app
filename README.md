# BudgetQuest

Gamifizierte Budget-App als browserbasierter Prototyp.

## Funktionen

- Dashboard mit Einkommen, Fixkosten, Monatsbudget und Sparstand
- Kategorien mit Budgetfortschritt
- Transaktionen erfassen
- Sparziele
- XP, Level, Missionen und Streaks
- Statistiken und Budget-Coach
- Speicherung direkt im Browser über `localStorage`

## Start

`index.html` direkt im Browser öffnen oder das Repository über GitHub Pages veröffentlichen.

## Hinweis

Die aktuell eingetragenen Zahlen sind Ausgangs- und Beispielwerte aus dem bisherigen BudgetQuest-Konzept. In einer nächsten Version können sämtliche Werte vollständig editierbar gemacht oder aus Excel/CSV importiert werden.
